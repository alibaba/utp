# 库存原语 — A2A 绑定

## A2A 绑定（A2A Binding） {#s-a2a-binding}

| 操作 | A2A Task Name |
| --- | --- |
| `set` | `utp:inventory:set` |
| `adjust` | `utp:inventory:adjust` |
| `query` | `utp:inventory:query` |
| `hold.query` | `utp:inventory:hold:query` |
| `批量 set/adjust` | `utp:inventory:batch（异步）` |
